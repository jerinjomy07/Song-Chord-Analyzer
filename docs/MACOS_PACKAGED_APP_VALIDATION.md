7. Strict adherence to [`shared/music_schema/song_analysis.schema.json`](file:///shared/music_schema/song_analysis.schema.json).

## 4. Packaged App Smoke Test & Loopback Security

### 4.1 Launch Lifecycle & Smoke Test
When launched with `--smoke-test`, `electron/main.cjs` executes the following sequence:
1. Electron initializes and selects a dedicated TCP loopback port (default `8000` or random unassigned port).
2. Spawns the packaged Python backend via `app.asar.unpacked/run_app.py`.
3. Passes `--host 127.0.0.1` (on macOS) and `--no-browser`.
4. Polls `http://127.0.0.1:<port>/api/health` until the health endpoint returns `{"status": "healthy"}`.
5. If `--smoke-test-exit` is provided, logs success and immediately terminates cleanly with exit code 0.

### 4.2 Loopback Network Security
- **macOS Default:** The backend binds strictly to `127.0.0.1` (loopback).
- **Audit Verification:** Sockets are verified using `lsof -nP -iTCP:<port> -sTCP:LISTEN`. The socket confirms `127.0.0.1:<port>`, preventing exposure to public or LAN interfaces (`0.0.0.0` or `*`).
- **Windows LAN Compatibility:** On Windows, the default remains `0.0.0.0` to preserve mobile companion APK functionality across local Wi-Fi.

1. **Gatekeeper Quarantine Bypass (Code Signing):**

2. **Native CoreAudio Playback:**
   - Verify low-latency audio output and waveform scrubbing through internal Mac speakers or headphones.
3. **Physical Offline Cold Launch:**
   - Disconnect network on a physical Mac and analyze a newly introduced audio file to confirm offline stem extraction without Wi-Fi.
